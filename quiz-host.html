🧪 Quiz Host Setup

Complete these steps once. Your questions live in a Google Sheet — no more editing JSON!

📋 Step 1 — Set up your Google Sheet

1

Open your Quiz Responses Google Sheet. Click the + tab at the bottom to add a new sheet. Name it exactly: Questions

2

In the Questions tab, add these column headers in row 1 (exact spelling):
Question  |  A  |  B  |  C  |  D  |  Correct  |  Completed

3

Fill in your questions starting from row 2. The Correct column should be one letter: A, B, C, or D. Leave the Completed column empty — the host will fill it in during the game.

4

Make sure the sheet is shared: Share → Anyone with the link → Viewer.

⚙️ Step 2 — Set up the Apps Script webhook

1

In your Sheet: click Extensions → Apps Script. Delete any existing code and paste in the script from the apps-script.gs file provided.

2

Click Deploy → New deployment → Web app. Set Execute as: Me. Set Who has access: Anyone. Click Deploy and copy the web app URL.

3

Paste that URL below.
